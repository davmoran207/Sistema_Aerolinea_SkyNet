# Sistema de Aerolinea SkyNet

Proyecto académico para la materia de Programación Orientada a Objetos.

## Descripción del Proyecto
SkyNet es un sistema de gestión por consola diseñado para controlar el inventario de vuelos, el registro de usuarios (pasajeros y empleados) y el procesamiento de ventas de boletos. El sistema aplica el patrón de arquitectura MVC (Modelo-Vista-Controlador) y maneja la información dinámicamente en memoria utilizando colecciones ArrayList, asegurando la integridad de los datos sin depender de bases de datos externas.

## Tecnologías Usadas
* Lenguaje: Java (JDK)
* Paradigma: Programación Orientada a Objetos (POO)
* Arquitectura: MVC (Modelo-Vista-Controlador)
* Entorno de Desarrollo (IDE): Apache NetBeans
* Gestor de Versiones: Git / GitHub

## Instrucciones de Ejecución
1. Clona este repositorio en tu máquina local:
   git clone https://github.com/davmoran207/Sistema_Aerolinea_SkyNet.git
2. Abre tu entorno de desarrollo Apache NetBeans.
3. Selecciona File -> Open Project... y elige la carpeta clonada.
4. Navega hasta el paquete principal: src/principal/Sistema_Aerolinea_SkyNet.java.
5. Haz clic derecho sobre el archivo y selecciona Run File (o presiona Shift + F6) para desplegar el menú interactivo en la consola.
